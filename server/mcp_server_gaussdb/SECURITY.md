# 安全与可靠性（0.8.0）

## 凭证与兼容性

继续复用现有 `huaweicloud_mcp_core`，不引入新的云端认证体系。
来源优先级仍是环境变量 → MCP 凭证文件 → devkit S1。
AK/SK/可选 STS Token 从选定来源成套读取；部分环境变量或部分文件凭证会报错，
不再跨来源补齐。Region 可独立覆盖。不同账号凭证文件中的 Project/Domain ID 不会继承到
环境变量账号；需要时使用显式环境变量指定，或通过 IAM 自动发现。
文件仍随每次工具调用重新读取；devkit 文件仍不强制 0600，MCP 自管文件仍要求私有权限。

## 通用接口与变更

`operation_policy.py` 保存已审核接口的风险清单。SDK 新增接口可以被发现和描述，
但 `reviewed=false` 时禁止调用，不能按名称自动获得写权限。
重置密码、修改授权、通用实例动作等操作使用 DANGEROUS 通道。
实例创建的兼容接口统一转向 `create_instance`；修改实例参数继续使用专用工具。

通用写入会递归收集实例 ID，包括批量数组，逐个读取云端实例以检查 ID、名称和标签保护。
目标不存在或查询失败即停止。有保护规则却无法解析实例目标时拒绝通用写入，
不推断备份、配置模板等其他资源的归属。云端资源匹配时保留 block / confirm / warn 的语义。
单次最多核实 100 个实例。保护检查与云端写入不是原子事务，云端 IAM 权限仍是最终权限边界。

创建、变更的 `is_auto_pay` 与 `is_auto_renew` 必须关闭；自动续费通过计费控制台管理。
包周期先产生待支付订单，再由客户端取得对具体订单、金额、币种的用户授权后调用 `pay_order`。
`confirm=true` 是请求参数，不是人工审批凭据；MCP 不提供可信审批签名或审批 UI。
付款前金额校验仍不是云端的原子扣款上限。

## 错误、日志与容量

所有 MCP 返回路径均执行脱敏，工具执行失败设置 `isError=true`。
审计分别记录 guardrail decision、outcome、error_code 与可用的云端 request_id。
正常通过护栏但业务失败不再记为操作成功。

进程最多保留 1000 条审计历史。文件默认达到 10 MiB 后轮转，最多保留 3 份历史文件；
新文件权限为 0600，拒绝符号链接及非私有的已有文件。文件写入错误会输出 ERROR 级
`audit_file_error`，保留 stderr 作为审计出口；这不是持久审计成功的保证。
生产应采集该事件并告警。轮转锁只覆盖单进程，多进程应使用独立文件或集中日志采集。

最多并行执行 16 个工具调用，SDK 工作池为 8 个线程、最多接纳 16 个执行中或排队请求。
容量已满返回 `MCP_BUSY`。GaussDB、CES、BSS、VPC 与 IAM 的 SDK 自动重试关闭，
连接/读取超时为 10/30 秒，异步 SDK 调用总等待上限 60 秒。
只有显式只读调用遇到 429/502/503/504 才退避重试，最多 3 次尝试。
创建 SDK 客户端及 IAM 自动发现移到工作线程，避免阻塞 MCP 事件循环。

尚未开始执行的排队请求在取消后不再派发。超时或客户端取消无法终止已发送的同步 HTTP 请求；工作线程在实际结束前仍占容量。
写请求超时或连接结果不确定时返回 `MCP_WRITE_RESULT_UNKNOWN`，不自动重试。
查询实例、任务或订单确认结果后再决定下一步。`wait_job` 的等待超时不会取消云端任务。

## HTTP 接入

stdio 启动方式不变。HTTP 默认监听 `127.0.0.1`，SDK 的 Host/Origin 防护保持开启。
非回环监听必须配置至少 32 字符的 `HUAWEICLOUD_MCP_HTTP_TOKEN` 和精确的
`MCP_SERVER_ALLOWED_HOSTS`；浏览器调用配置 `MCP_SERVER_ALLOWED_ORIGINS`，不接受通配符。
每个请求都需携带 `Authorization: Bearer <MCP token>`，不能用云端 AK/SK 代替。
Token 在启动时读取，轮换 HTTP Token 后重启服务；云端凭证文件仍支持热加载。

远程部署在 HTTPS 网关后面，例如绑定内网地址，允许 Host 为 `mcp.example.com`、
Origin 为 `https://agent.example.com`；网关保留公共 Host 并转发到 MCP 的 `/mcp`。
访问不经过网关的后端端口应由网络策略限制。不要把 Token 经公网明文 HTTP 发送。
每次 HTTP 请求均检查 Token，限制消息体 1 MiB、最多 128 会话、会话空闲 300 秒失效。
不信任转发头来改变调用者身份。

该共享 Token 是接入校验，不是 MCP OAuth 授权服务器，也不提供按用户划分的 IAM 身份。
多用户需要独立身份服务或认证网关；要求标准 OAuth 发现的客户端由相应网关接入。
