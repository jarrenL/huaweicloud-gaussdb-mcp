# 验收标准

## 概述

以下条件用于判断 `huawei-cloud-gaussdb-manage` 是否可以提交到华为云 Skills 开源仓库。

## 结构与元数据

| 检查项 | 通过标准 | 失败示例 |
|---|---|---|
| 目录 | 位于 `skills/database/gaussdb/huawei-cloud-gaussdb-manage/` | 放在仓库根目录或名称不一致 |
| Frontmatter | 包含 `name`、`description`，并在 `metadata` 中记录 `tags`、`version` | 缺字段或 `name` 与目录不一致 |
| 标签 | 最多 5 个，均与 GaussDB/MCP 相关 | 使用大量泛化标签 |
| 自包含 | 所有引用均在 Skill 包内且相对路径有效 | 依赖本机绝对路径或外部网页 |
| 大小 | SKILL.md 少于 500 行，Skill 包小于 5 MiB | 大段复制 SDK 或 OpenAPI 全量文档 |

## 功能行为

| 场景 | 通过标准 | 失败标准 |
|---|---|---|
| 实例查询 | 先 list 后 get，资源身份明确 | 猜测实例 ID 或复用旧会话 ID |
| 创建选型 | 通过实时发现取得版本、部署、规格、AZ 和网络 | 写死区域规格或默认成高成本形态 |
| 创建实例 | 展示完整脱敏计划、明确授权、跟踪任务并复查 | 仅返回“请求成功”或泄露密码 |
| 参数修改 | 先读可修改元数据，校验值域和风险，写后复查 | 盲写、高危参数无预览或确认 |
| 备份策略 | 正确区分星期 `period` 和分钟 `differential_period` | 原样使用错误字段名或错误单位 |
| OpenAPI | list → describe → 匹配风险通道 | 猜请求字段或绕过专用工具 |
| 询价 | 规格实时发现后调用 BSS，区分按需/包周期并标注估算假设 | 把规格码当价格、猜商品编码或编造金额 |
| 主备切换 | 读取组件、精确确认、危险通道调用、跟踪任务并复查角色 | 对单副本切换、猜组件 ID 或自动重试 |
| EIP | 通过 VPC/EIP 创建，再由 GaussDB 绑定已有 EIP 并复查 | 把 EIP 创建请求发给 GaussDB 或猜测公网 IP ID |
| 数据面路由 | SQL/DDL 路由到数据面 MCP | 通过管控面 OpenAPI 执行任意 SQL |
| 删除 | 重新读取资源、检查保护项、精确确认、跟踪完成 | `confirm=false` 仍删除或删除错资源 |

## 错误处理

- 凭证缺失：返回缺少的来源或字段，不回显任何已读取的凭证。
- 权限不足：返回最小授权项、区域范围、错误码和请求 ID，不自动升级到管理员权限。
- 资源不存在：停止写操作并要求重新发现，不重试随机 ID。
- 区域无资源：说明这是区域/租户可售性结果，提供实时可用候选，不认定为代码缺陷。
- 异步失败：返回 `job_id`、失败阶段和云端原因，不把受理状态报告为完成。
- 网络超时：只对幂等只读调用做有限重试；写操作先查询任务或资源状态，避免重复创建。

## 安全验收

必须全部通过：

- 无真实 AK/SK、SecurityToken、数据库密码、私钥或完整慢 SQL 样本。
- 默认只读验证不产生费用或资源变更。
- 所有 DANGEROUS 工具要求 `confirm=true`。
- 询价和余额查询不构成创建、下单或自动支付授权。
- 普通写操作遵守只读模式、自定义护栏和保护名单。
- 生产资源操作前说明影响、维护窗口、备份和回滚条件。
- 任何自动清理都需要用户对精确资源的删除授权。

## 兼容性验收

- Python 3.10、3.11、3.12 至少覆盖当前 MCP 工程声明的版本。
- MCP Server 版本不低于 0.6.0，tools/list 返回不少于 27 个工具并包含 `wait_job` 等关键工具；允许向后兼容地
  新增工具。
- 能从源码工作区启动；PyPI 未发布时文档不声称 `uvx` 可以直接下载。
- devkit S1、显式环境变量和 MCP 凭证文件三种来源的优先级说明与实现一致。
- Project ID 缺省时能够按 region 自动发现；无法唯一匹配时给出可操作错误。
- `scripts/smoke.py` 能完成 initialize、tools/list、只读查询和 `MCP_READ_ONLY` 护栏验证，且不
  输出资源详情或凭证。

## 提交前结论

只有静态验证、本地启动、只读云端验证和安全扫描全部通过，才可提交 PR。会产生费用的创建、
扩容、规格变更和包周期操作不是默认验收前提；若执行，PR 必须附脱敏验证报告和清理结果。
