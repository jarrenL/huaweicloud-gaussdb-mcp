# 购买前选型与询价

## 目标

在创建 GaussDB 前，把技术规格、实时可售性、官方价格和账户预算放在同一份决策结果中。
本流程只生成购买计划和报价证据，不代表已授权创建、下单或自动支付。

## 决策输入

至少收集以下信息：

| 类别 | 输入 |
|---|---|
| 使用场景 | 开发测试、生产高可用、大容量/横向扩展 |
| 区域 | 华为云 region，例如 `cn-north-4` |
| 数据库 | 产品类型、集中式/分布式、版本 |
| 计算 | 规格码、CPU/内存目标、节点/副本数量 |
| 存储 | 存储类型、初始容量、预期增长量 |
| 网络与保护 | EIP、备份保留期、跨区域或容灾要求 |
| 计费 | 按需或包年/包月、购买时长、自动支付选择 |
| 预算 | 预算上限、币种、是否允许使用优惠价格 |

## 三档候选

先调用 `discover_create_options` 和 `list_flavors`，再根据实时返回生成候选：

| 档位 | 典型形态 | 使用边界 |
|---|---|---|
| 开发测试 | 集中式 `single` | 成本优先，不具备生产高可用能力 |
| 生产高可用 | 集中式 `triset` | 1 主 2 备，适合需要节点级高可用的业务 |
| 大容量/横向扩展 | 分布式 `combined` 或 `hws` | 规格和产品类型必须按区域实时验证 |

这三档是比较框架，不是默认购买建议。某一区域缺少某个形态时，展示当前真实候选，不用其他
区域的规格替代。

## BSS 查询流程

GaussDB MCP 的 BSS 客户端覆盖已有订单查询、确认付款与取消。购买前询价和余额仍需使用
独立的华为云计费/BSS 工具、API Explorer 或受控的 BSS SDK/CLI，不能把 GaussDB OpenAPI
调用通道用于 BSS 请求。`get_order` 可查看下单后的金额，不替代购买前报价。

1. 按需报价：`ListOnDemandResourceRatings`。
2. 包年/包月报价：`ListRateOnPeriodDetail`。
3. 当前账户余额：`ShowCustomerAccountBalances`。

官方参考：

- [查询按需产品价格](https://support.huaweicloud.com/api-bpconsole/bcloud_01001.html)
- [查询包年/包月产品价格](https://support.huaweicloud.com/intl/zh-cn/api-bpconsole/bpconsole-api-zh-pdf.pdf)
- [查询账户余额](https://support.huaweicloud.com/api-oce/mac_00001.html)

询价前先通过 BSS 商品目录或价格计算器确认以下商品字段：

- `cloud_service_type`
- `resource_type`
- `resource_spec`
- `region`
- `usage_factor`
- 容量、数量、使用时长及其度量单位

`spec_code` 是 GaussDB 规格发现结果，不保证可以直接作为 BSS 的 `resource_spec`。没有得到
商品目录的明确映射时，停止自动询价并说明缺少的映射，不猜测字段。

## 余额与权限

余额查询只能使用客户自身凭证或符合账号体系要求的授权，并需要 `billing:balance:view`。
伙伴账号、客户账号和 IAM 用户的可用 BSS 接口及授权模型不同。权限不足时只返回错误码、请求
ID 和所需权限，不要求用户在对话中提供 AK/SK，也不自动提升权限。

## 成本计算规则

1. 保留 BSS 返回的官网价、优惠额、成交价、币种和度量单位。
2. 计算、存储、备份、公网和其他资源分别计价，再汇总，避免遗漏线性计费项。
3. 按需接口返回小时单价时，可以计算 `小时单价 × 用户认可的月小时数`；默认不得悄悄采用
   730 小时。输出必须标注这是月度估算，不是账单承诺。
4. 包周期使用 `ListRateOnPeriodDetail` 的期限和金额，不用按需单价乘月份代替。
5. 比较成交价与可用余额时，同时列出欠款、专款专用限制和未计入项目。余额不足只提示，不能
   自动充值、下单或切换计费方式。

## 输出模板

```text
状态：报价完成 | 部分报价 | 未取得权威报价
区域：<region>
查询时间：<带时区的时间>
方案：开发测试 | 生产高可用 | 大容量/横向扩展
配置：<产品/版本/部署形态/规格/节点/存储>
计费：<按需或包周期，期限>
价格：<官网价、优惠、成交价、币种、单位>
余额：<可用余额、欠款；无权限时明确写未查询>
估算假设：<月小时数、增长量、未计入项目>
证据：<BSS 请求 ID 或价格计算器结果引用>
下一步：<需要用户选择并确认的方案>
```

任何状态下，报价查询都不构成 `create_instance` 授权。创建前仍需按 SKILL.md 展示最终参数、
费用影响和资源清理方式，并取得针对该方案的明确确认。
